# 使用通用任务链路 IR 作为产品核心

B-A-T 将自然语言浏览器任务编译为参数化、版本化、可验证、可复跑的通用任务链路。平台公共 contracts 和 runtime 只拥有浏览器能力、观察、数据处理、控制流、链路调用、人工等待、显式模型、检查点、输出和终止等通用语义；网站名称、业务实体和字段作为任务版本的动态输入输出契约保存。这样可以让一次模型探索形成的路径由普通执行器在不同输入上复跑，同时避免把首个数据采集样例演变成产品架构。

运行图的异步推进、循环调度、取消和递归上限复用 LangGraph `StateGraph`。`TaskChainRuntime` 是受控 IR 到该引擎的产品适配层，负责 B-A-T 自有的预算、值绑定、幂等、副作用审计和运行结果投影；它不得演变为手写的通用图调度器。

## Consequences

- BrowserSkill 是浏览器能力提供者，不拥有链路编译、持久化和复跑。
- 复杂任务通过链路调用与集合逐项执行组合，不复制同构链路。
- `TaskRun`/`TaskCheckpoint` 继续由现有 SQLite/Drizzle 产品仓储持久化，因为它们是用户可见、带版本和审计的产品事实；不再建立一份 LangGraph 专用 SQLite 作为第二事实源。
- 删除成熟库或框架前必须证明对应能力已从产品移除；若能力仍在，保留或替换为另一成熟组件，禁止用项目代码从零复刻。
- 现有偏向数据采集的固定输入、行结果和提取节点合同需要按架构基准重新审计；迁移前不得继续增加网站或任务专用公共类型。
