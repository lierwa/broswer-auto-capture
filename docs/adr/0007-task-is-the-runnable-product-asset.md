# 任务通过不可变运行版本成为可运行产品资产

B-A-T 不新增一个与任务并列的“链路项目”或“自动化脚本”实体。用户创建的任务始终是唯一产品资产；需求、准备、运行和修复历史都归属于它。任务只有在发布一份固定 requirement、plan、全部 chain version/digest 与 E1-E4 证据的不可变运行版本，并绑定一个通过输入合同校验的运行预设后，才投影为可运行任务。

直接运行必须消费该发布清单，不能在点击时临时选择“数据库中最新的已验证链”。修复产生新候选且不改写当前发布版本；新候选完成验证后再原子发布。运行预设只保存默认业务输入和执行节奏，不进入链路 digest，也不能改变节点语义。这样避免任务与链路库形成两个相互漂移的管理入口，同时保证一键运行、服务重启和修复发布都能解释实际执行的是哪个版本。
