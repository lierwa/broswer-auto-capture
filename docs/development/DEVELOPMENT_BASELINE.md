## 1. 本次收口是什么意思

当前原型作为布局与交互基线，不继续无业务依据地重新设计整页。负责人没有确认所有业务状态的最终画面，也不需要在开发前逐张设想全部画面。后续按功能补齐状态、真实数据投影及恢复动作，用可操作页面验收；必要的局部调整可以实施，改变导航、核心工作区或业务授权边界时另行说明。

文档收口阶段仅整合文档；2026-09-06 F1 接续已完成正式任务/访谈切片，当前范围与证据见 PROGRESS，后续按 ROADMAP 推进。

## 4. 实现与 UI 同步的最小交付单元

每个功能必须一起交付：

1. 真实输入与归属：taskId、关联版本、用户授权；跨边界 Zod 校验。
2. 持久事实和事件：定义谁负责写入、哪些变化使旧产物待复核；模型线程不是事实源。
3. 可操作界面：正常路径和本功能的等待/失败/取消/受限状态；采用 UI_STATES 与现有信息承载规则。
4. 恢复与保护：切任务不串结果，重复提交不重复副作用，刷新不伪造完成；已有历史可读。
5. 验收证据：协议测试、相关集成测试和可见 UI 回归。替身/样例/真实调用分别标记；真实运行另核对 canonical 记录和审计。

测试夹具允许有代表性数据，以覆盖丰富状态，但必须隔离于真实任务，不放入生产默认状态。不要为了截图把数据库、计数或执行结果直接写成成功。
