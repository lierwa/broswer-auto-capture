## 范围与方式

用户授权同步文档后启用一个对抗 subagent。主 agent 修改文档；独立审查 agent `/root/adversarial_capture_document_review` 只读审查 [主方案](WORKFLOW_AND_DELIVERY_REBUILD_20261005.md)、RESEARCH 最新复用记录、ROADMAP/PROGRESS 最新状态和旧修复文档替代声明，以 AGENTS.md 和 TASK_CHAIN_ARCHITECTURE.md 为边界。审查没有开浏览器、运行服务、测试、修改生产文件或派发其它 agent。

重点是直接复用成熟内容采集能力、范围采集与最终字段分离、清洗移出本轮、原生探索到普通复跑、动态输入/分支/循环、任务浏览器及独立资源归属。审查不把源码接口存在当成完整业务通过。
