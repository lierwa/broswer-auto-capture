# A · 动作记录与上下文还原

## 目标与接口

输入：当前 Browser 会话中的原生动作及公开结果。

输出：可保存、加载和关联的动作记录，包括动作身份、原始参数、派发状态、目标上下文、动作结果和所属 document/frame。点击记录同时区分意图目标与实际事件命中。

## 修改位置

Python 路径前缀：`vendor/workflow-use/workflows/workflow_use/hybrid/`。

| 文件 | 修改职责 |
| --- | --- |
| `action_identity.py`、`action_dispatch.py` | 原生 history 位置、派发尝试和事件身份关联 |
| `capture.py`、`dom_evidence.py` | 同步取得真实事件及局部 DOM 值，接收至宿主 |
| `history.py`、`normalize.py` | 将动作、观察及结果按统一身份保存 |
| `author.py`、`natural_facts.py`、`bindings.py` | 原值保全、输入与前步输出引用 |
| `capability.py` | 交付下游需要的公开动作结果 |

跨语言变更同步 `apps/api/src/upstream-browser/hybrid-protocol.ts` 与 `apps/api/python/browser_use_runner/hybrid_main.py`。

## 实现

1. 核验固定版本 b-u 提供的事件订阅和 DOM 能力。优先使用原生接口；缺少真实点击事件时，增加局部事件监听适配，复用当前 Browser 会话。
2. 在动作派发前完成所属 document 的监听注册。捕获阶段同步复制 `event.target`、可取得的 `composedPath()`、实际祖先关系、所需子节点及属性。回调中不等待异步查询后再读取目标，不保存供后续访问的活 DOM 引用。
3. 采集范围由本次目标及所需上下文决定。需要更深层内容时对该局部查询；不导出整页 HTML，不遍历根祖先的全部后代，不静默截断执行数据。
4. 派发前将本次动作身份与 document 关联。重复参数、失败无回调、一个动作产生多个事件均保留真实记录。脚本事件与用户输入事件分别记录；`isTrusted` 不单独决定事件归属。
5. 点击导致跳转或节点删除时，先同步取值并经会话通路送到宿主。以宿主实际接收为成功依据。新 document/frame 注册独立监听；会话关闭时释放监听和绑定。
6. Shadow DOM 记录监听器实际看到的 target、事件路径及原生补充证据。关闭 root 内部节点若不能由外层事件路径取得，核验原生 DOM 能力补充，标明来源与缺失边界。iframe 按自己的 document/frame 身份采集。
7. 原始参数和公开 ActionResult 保留原值；摘要用于完整性校验。输入/前步输出引用必须有真实来源，多处输入同值时不得随意绑定首项。
8. 点击未派发、事件未捕获、结果未收到分别记账。缺失证据不能用意图目标、样本内容或猜测值补写。

## 替换或删除

删除按回调计数/参数相等猜动作身份的分支、执行值哈希替代、整页采集、点击结束后猜上下文的逻辑。需要向后续节点交付结果的动作不能统一返回空值。变更前核实消费者，原始运行产物保持不变。

## 独立验收

使用实际 b-u 原生点击经过正式采集入口；页面记录业务 handler 次数及实际事件，和宿主动作记录对照。

| 场景 | 通过条件 |
| --- | --- |
| 点击按钮内 span/icon | 实际 target 与按钮/祖先关系正确，业务处理一次 |
| 连续同参点击、无回调失败、脚本额外事件 | 动作身份不漂移，额外及缺失事件明确 |
| 立即导航、立即删除目标 | 宿主收到动作发生时的局部值，新页首个动作可采集 |
| shadow/slot、同源与跨源 iframe、frame 重建 | 所属 document/frame 和真实可见路径正确，缺失边界明确 |
| 输入、控制键、带 query/fragment 的地址、动作结果 | 正式保存加载后原值及引用关系正确 |

受控页面通过后，在实际任务页面验证相同入口。交付受支持范围、原生接口依据、真实事件与动作对照、存储往返结果。完成后进入 [B](B_DOM_TARGET_READ.md)。
