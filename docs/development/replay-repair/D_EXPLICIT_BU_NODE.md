# D · 显式 b-u LLM 节点

## 目标与接口

在当前 Browser 会话中，复用 b-u 的 DOM/截图观察、模型判断和工具操作，完成一个指定的局部任务。

输入为局部目标、必要的本次运行数据及结果合同。Browser、允许动作、模型连接、预算和审计由运行时注入。输出为任务结果、当前浏览器状态、实际动作/模型调用及未决效果。

适用场景：复杂页面状态判断、视觉/语义操作、无法可靠枚举的交互，以及未知弹窗等临时干扰。确定性步骤使用普通能力；本节点可以多轮调用模型。

## 修改位置

| 位置 | 工作 |
| --- | --- |
| vendor `hybrid/author.py` | 复用原生 Agent/Tools 构造及观察接线，分离首次编译职责 |
| vendor `hybrid/annotations.py`、`semantic.py` | 核对现有语义接口的适用范围 |
| API `upstream-browser/model-bridge.ts` | 沿现有产品模型路由连接与审计 |
| API `upstream-browser/hybrid-runtime.ts`、Python runner | 提供当前 Browser 的有界调用及取消通路 |
| API `upstream-browser/hybrid-materializer.ts`、`task-chain/runtime-host.ts` | 将能力接入显式 llm 节点、分支及结果绑定 |
| 现有 llm 节点合同 | 按需最小扩展工具能力配置，保持普通节点模型隔离 |

先用固定版本公开 API 验证共享 Browser、图像观察、工具权限和取消能力，再确定 adapter。直接调用整个 authoring 流程会混入首次探索/编译职责，应只复用原生 Agent 能力。

## 实现

1. 任务链显式声明此节点及其入口。可以是必要业务步骤，也可以是干扰分支；未进入时不启动 Agent、不调用模型。
2. 为 b-u 提供局部目标和当前必要观察。LLM 无需填写 session/tab、摘要、技术预算或图结构。
3. 节点借用当前产品 Browser，独占该段操作；不另起浏览器。原生 Agent 管理内部观察/动作循环，LangGraph 管理节点推进。
4. 使用现有步骤/时间预算并传播取消。记录每次模型调用、工具动作、实际命中及结果；借用节点退出不关闭外层所有者的会话。
5. 对可确定性检查的后态再次核验。结果与当前状态交回主链，由主链决定下一步。模型声明完成不能替代可验证的页面结果。
6. 干扰处理成功后返回原业务步骤的准备/结果核验位置。业务动作已派发时先判断其实际结果，不直接重发。
7. 无法确定副作用、预算耗尽或遇到登录/验证码时，沿既有暂停/失败/人工处理出口保留状态。
8. 首次探索中无法可靠转换为普通能力的必要操作段，可编译为此节点；动作覆盖、输入输出绑定和模型审计仍须完整。

## 弹窗处理

将弹窗处理作为有条件的干扰分支，保持业务步骤位置。只有确认为干扰的弹窗才允许关闭；业务确认框按任务含义处理。

| 当前状态 | 行为 |
| --- | --- |
| 没有阻挡 | 执行主流程，不查找或等待关闭按钮 |
| 有阻挡且存在已验证的处理方法 | 普通能力处理，重查原目标后继续 |
| 有陌生阻挡或处理条件难以可靠表达 | 进入本节点，让 b-u 判断并完成局部处理 |
| 弹窗在派发后出现 | 核对实际命中和业务结果，避免重复副作用 |
| 干扰反复出现或无法处理 | 按预算暂停，保留主流程位置和未决效果 |

录制时是否出现弹窗不决定复跑时必须执行关闭动作。录制有而复跑无时跳过；录制无而复跑有时，按当前状态进入适用处理分支。

## 替换或删除

删除普通节点内部的模型 fallback、整任务重新探索、无条件关闭步骤及站点弹窗枚举。复用原生 Agent loop，不自建模型/工具循环。文本 summary 与可操作浏览器的 Agent 能力分别准入。

## 独立验收

| 场景 | 通过条件 |
| --- | --- |
| 无干扰的普通流程 | 此节点未进入，实际模型调用为零 |
| 录制/复跑弹窗有无的四种组合 | 同一主链可继续，无缺关闭按钮错误 |
| 未录制的新布局弹窗 | b-u 使用实际 DOM/截图完成处理，开发者不注入 selector 或答案 |
| 业务 dialog、派发后弹出、重复弹出 | 不误取消业务、不重复提交，游标和效果记录正确 |
| 节点超时/取消 | 会话所有权不变，调用与未决效果可追踪 |
| 非弹窗的视觉/语义局部任务 | 同一节点能力可复用，结果由实际页面验证 |

通过正式 llm 节点入口执行，交付 Browser 会话身份、局部目标、真实动作、模型调用、后态和恢复位置。至少覆盖一个未预置布局的现场。
