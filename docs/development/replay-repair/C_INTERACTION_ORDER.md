# C · 交互执行与异步顺序

## 目标与接口

输入：当前浏览器作用域、动作参数、B 提供的目标，以及动作前置/结果条件。

输出：实际执行结果、当前浏览器状态、派发记录及完成/未决状态。下一步只在所需条件满足后推进。

## 修改位置

Python 路径前缀：`vendor/workflow-use/workflows/workflow_use/hybrid/`。

| 文件 | 修改职责 |
| --- | --- |
| `capability.py`、`targets.py` | 统一准备、派发、结果交付 |
| `target_scroll.py` | 目标滚动与实际滚动容器 |
| `postconditions.py`、`visible_wait.py` | 前置/后态检查、观察重试、取消 |
| `natural_effects.py`、`post_action_target.py` | 实际结果和可操作状态采集 |
| `natural_compile.py`、`visible_wait_compile.py`、`causal.py` | 从真实任务与执行证据建立条件及辅助动作归属 |

内部命令变更同步 API `hybrid-protocol.ts`、`hybrid-materializer.ts`、`hybrid-runtime.ts`、`hybrid-runtime-scope.ts` 及 Python runner 的 `StepCommand`。

## 执行顺序

**确认作用域 → 定位目标 → 必要滚动 → 核验可操作与命中 → 派发动作 → 等待具体结果 → 交付并推进。**

1. 使用本次 session/tab/document。URL 用于地址/作用域核验，不承担 DOM 就绪或业务完成判断。
2. 点击前检查可见、可用、必要布局稳定及命中关系；接受目标子节点命中，拒绝遮挡。滚动或布局变化后重新定位，复用原生派发前检查。
3. 目标已在 DOM 中时，使用原生 scrollIntoView 滚动正确窗口/容器；已可操作则不多滚。目标缺失时先查实际状态，不盲滚。
4. 需要懒加载时，使用既有动作、观察和 LangGraph 循环，检查内容进展、加载状态、触底及目标出现。正在加载就等待；无进展则按预算退出。
5. 业务动作位于观察重试之外。复用 StepVerifier/Tenacity，只重查条件；原生动作自身的重试语义必须核清。
6. 条件由下一步目标/ReadSpec、动作结果和探索时验证过的事实产生。无法可靠表达的判断进入 D 的显式节点。
7. 导航等待生命周期及所需 DOM；输入后检查本次值和其触发的异步结果；翻页等待新页身份与必要字段。已满足条件可直接继续，不统一要求页面发生变化。
8. 前置条件接到派发前，后态接到派发后；结果区可使用独立的稳定目标或 ReadSpec。现有命令表达不足时做最小内部扩展，由程序补齐政策字段。
9. 固定时间只作为可选缓冲，timeout 是失败上界。广告造成的遮挡/焦点改变必须处理；网络是否空闲不能代替目标和结果检查。
10. 派发后结果不明时保留未决效果。取消传播至观察，恢复继续同一运行并核验浏览器状态；不得通过重放整段重复业务副作用。

分页组合为：定位分页器并滚入视口 → 点击一次 → 新页身份及字段就绪 → 读取。旧列表仍显示或容器已可见，都不能提前满足新页读取条件。

## 替换或删除

替换固定滚动次数、探索像素坐标、固定秒数完成、URL/title-only 完成、任意 changed 完成、visible 即可点击、轮询内重派及各动作独立等待器。`snapshot_consistency.py` 仅保留采样身份检查职责。

## 独立验收

| 场景 | 通过条件 |
| --- | --- |
| 窗口/嵌套容器、布局移动、目标缺失 | 滚对目标，重新核验命中；不盲滚或错点 |
| 即时、延迟超过三秒、永不完成 | 条件满足后推进；业务动作计数正确；超时不抢跑 |
| 导航后延迟 DOM、同 URL 刷新 | 不读取旧列表或未填完整字段 |
| 分页、详情返回、懒加载触底 | 页身份、读取顺序和返回位置正确；无进展有限退出 |
| 输入/选择/按键 | 参数、值、焦点正确；异步结果独立等待 |
| 遮挡、取消、document 替换、恢复 | 无错误目标副作用和重复提交；未决状态保留 |

受控浏览器现场使用可重复时序验证竞态，再通过同一入口验证实际任务页面的分页与往返。交付派发次数、条件读值、页面实际结果和恢复记录。
