3. 正常发布和正式运行；通过结束节点查看与已确认需求一致的成果。
4. 同一不可变版本再次运行，核验运行隔离、参数、模型审计及任务资源回收。
5. 正常主流程通过后，断线恢复作为独立验收项；正常连接或单次成功不能证明恢复能力。
